# Менеджер форм

Микросервис на go lang, хранящий настройки форм обратной связи и результатов заполнения.  
В системе присутствует аутентификация, которая позволяет разграничить права доступа к настройкам и чувствительным данным.

Каждый пользователь может создавать свои уникальные формы. Сервис не предоставляет UI интерфейс и все взаимодействие происходит через API.

> Еще на стадии разработки

## Запуска в docker

В корне проекта необходимо создать `.env` файл, где хранится информация, для сборки контейнера.  
В корне проекта размещен файл-пример `.env.example`

## Описание API методов

Все доступные API методы описаны через [swagger](http://feedback.127.0.0.1.nip.io/docs/swagger/)
Для генерации swagger нужно в корне проекта выполнить команду

```bash
swag init -g cmd/api/main.go
```
